🔐 **Cybersecurity Lab: Password Recovery with John the Ripper and Hash Calculator**

I documented a hands-on, screenshot-based lab exploring how password-auditing tools can be used for authorized password recovery on a sample password-protected PDF.

In this walkthrough, I:

✅ Set up John the Ripper Jumbo on Windows  
✅ Prepared a PDF hash for testing  
✅ Performed a dictionary-based password audit  
✅ Compared the workflow with the Network Walks Hash Calculator and Password Cracker  
✅ Investigated a failed attempt caused by a limited wordlist  
✅ Updated the wordlist and verified a successful recovery

The biggest takeaway was that password security is strongly influenced by both password strength and wordlist coverage. A weak or predictable password can be exposed by an offline dictionary attack, while a long, unique passphrase is considerably more difficult to guess.

This project was completed for educational purposes using authorized lab material. Password-cracking techniques should only be used on files, hashes, and systems you own or have explicit permission to test.
